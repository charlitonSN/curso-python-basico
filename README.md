## 📚 Conteúdo do repositório

Este repositório reúne exercícios e exemplos práticos desenvolvidos durante meus estudos introdutórios de Python.

Ao longo do aprendizado, serão explorados conceitos fundamentais da linguagem, como variáveis, tipos de dados, operadores, estruturas condicionais, estruturas de repetição, funções e outros recursos.

### 💻 Projeto prático: Calculadora

Como aplicação dos conhecimentos adquiridos, será desenvolvida uma calculadora em Python de forma progressiva.

A cada novo conceito estudado, novas funcionalidades e melhorias serão incorporadas ao programa, permitindo aplicar na prática os fundamentos da programação e acompanhar a evolução do projeto.
